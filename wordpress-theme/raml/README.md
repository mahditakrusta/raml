# 🏺 قالب رَمل — فروشگاه سفال و سرامیک

قالب وردپرس زیبا و حرفه‌ای برای فروشگاه‌های سفال، سرامیک و صنایع دستی ایرانی.

![رَمل Theme](screenshot.png)

## ✨ ویژگی‌ها

- **طراحی راست‌چین (RTL)** — کاملاً سازگار با زبان فارسی
- **سازگاری کامل با WooCommerce** — همه قابلیت‌های فروشگاهی
- **کاملاً واکنش‌گرا** — نمایش عالی در موبایل، تبلت و دسکتاپ
- **فونت وزیرمتن** — تایپوگرافی زیبای فارسی
- **رنگ‌بندی سفارشی** — پالت رنگی گرم و زمینی مناسب سفال
- **صفحه اصلی جذاب** — هیرو، دسته‌بندی‌ها، محصولات ویژه
- **انیمیشن‌های ظریف** — تجربه کاربری روان
- **سبد خرید AJAX** — افزودن محصول بدون بارگذاری مجدد
- **تنظیمات سفارشی‌ساز** — ویرایش آسان از پنل وردپرس

## 📦 نصب

### پیش‌نیازها
- وردپرس نسخه ۶.۰ یا بالاتر
- PHP نسخه ۸.۰ یا بالاتر
- افزونه WooCommerce نسخه ۸.۰ یا بالاتر

### مراحل نصب

1. **دانلود قالب**
   - فایل‌های قالب را در یک پوشه به نام `raml` قرار دهید
   - آن را فشرده (ZIP) کنید

2. **آپلود در وردپرس**
   - به پنل مدیریت وردپرس بروید
   - نمایش → پوسته‌ها → افزودن پوسته جدید
   - روی «بارگذاری پوسته» کلیک کنید
   - فایل ZIP را انتخاب و نصب کنید

3. **فعال‌سازی**
   - پس از نصب، روی «فعال‌سازی» کلیک کنید

4. **نصب WooCommerce**
   - اگر WooCommerce نصب نیست، از بخش افزونه‌ها نصب کنید

5. **تنظیمات اولیه**
   - به نمایش → سفارشی‌سازی بروید
   - تصویر هیرو و متن‌ها را تنظیم کنید
   - اطلاعات تماس را وارد کنید

## ⚙️ تنظیمات سفارشی‌ساز

### بخش هیرو
- **عنوان هیرو**: متن اصلی صفحه نخست
- **توضیحات هیرو**: متن توضیحی زیر عنوان
- **تصویر پس‌زمینه**: تصویر بزرگ هیرو

### اطلاعات تماس
- **شماره تماس**: شماره تلفن فروشگاه
- **ایمیل**: آدرس ایمیل
- **آدرس**: آدرس فیزیکی فروشگاه

## 🎨 سفارشی‌سازی رنگ‌ها

رنگ‌های اصلی قالب در فایل `style.css` تعریف شده‌اند:

```css
:root {
    /* Sand - رنگ‌های شنی */
    --sand-50: #fdf8f0;
    --sand-500: #d88a2e;
    
    /* Clay - رنگ‌های خاک رس */
    --clay-500: #b47254;
    --clay-600: #a66149;
    
    /* Earth - رنگ‌های زمینی */
    --earth-500: #97875b;
    --earth-950: #2b221a;
}
```

```
│   ├── css/
│   │   └── woocommerce.css  # استایل اضافی ووکامرس
│   └── js/
│       └── main.js          # جاوااسکریپت قالب
└── README.md              # این فایل
```
